# Mekatronik Mini Proje Portföyü

Bu klasör, Python öğrenme sürecinde geliştirilen ilk küçük mekatronik odaklı uygulamaları içerir.

## Projeler

### 01 — Motor Hızı Kontrolü
Kullanıcıdan 0–100 arasında motor hızı alır ve motorun durumunu düşük/orta/yüksek hız olarak belirler.

Öğrenilenler:
- `input()`
- `int()`
- değişkenler
- `if / elif / else`
- `==` ve karşılaştırma operatörleri

### 02 — Sıcaklığa Göre Motor Kontrolü
Sıcaklık değerine göre motorun kapalı, düşük, orta veya yüksek hızda çalışacağını belirleyen simülasyon.

### 03 — Sıcaklığa Göre LED Kontrolü
Sıcaklığa göre LED'in kapalı, yanıp sönen veya açık olduğunu simüle eder; yüksek sıcaklıkta uyarı verir.
 
> Not: Bu projeler eğitim amaçlı Python simülasyonlarıdır; gerçek motor/LED donanımı doğrudan kontrol etmez.
