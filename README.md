# 🤖 Mechatronics Mini Project Portfolio

This repository contains my first Python projects as a mechatronics student.

I am learning Python step by step and using these projects to build a foundation for future work in electronics, robotics, sensors, motors, and automation.

## 📂 Projects

### 01 - Motor Speed
A simple Python program that determines the motor operating level based on the entered speed percentage.

**Concepts learned:**
- `input()`
- Variables
- `int()`
- `if / elif / else`
- Comparison operators

---

### 02 - Temperature → Motor
A simple simulation that determines the motor operating level according to the entered temperature.

**Concepts learned:**
- Conditional statements
- Comparison operators
- Multiple conditions

---

### 03 - Temperature → LED
A simple simulation that controls the LED state according to temperature and displays a warning when the temperature is too high.

**Concepts learned:**
- `if / elif / else`
- Multiple outputs
- Conditional logic

---

### 04 - Age Calculator
A simple Python program that asks for the user's name and age, then displays their current age and calculates their age 5 years later.

**Concepts learned:**
- `input()`
- `int()`
- Variables
- Basic arithmetic operations
- `print()`

---

### 05 - Password Checker
A simple Python program that checks whether the entered password is correct.

**Concepts learned:**
- `input()`
- `int()`
- `if / else`
- `==` comparison operator
- Conditional logic

> Note: This project is for learning purposes. Hard-coding a password is not a secure approach for real applications.
